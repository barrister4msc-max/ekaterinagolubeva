# Archived Supabase migrations

These 41 files are the original KATI LAWYER migration chain preserved byte-for-byte.

They are intentionally outside `supabase/migrations` because the original order
fails on a fresh Preview database after the fifth migration. Do not move them
back into the active directory or execute them after the replacement baseline.

The active replacement is:
`supabase/migrations/20260815083345_kati_lawyer_replacement_baseline.sql`.

Production migration-history reconciliation is a separate controlled operation
and is not authorized by this archive.
